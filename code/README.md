# 재현 코드

`python verify.py`는 원본 데이터 없이 `out/`의 결과 파일로 발표 숫자 21개를 대조합니다.

| 폴더 | 하는 일 | 발표 |
|---|---|---|
| `01_전처리/` | 과제 데이터 정제, 행정동 기본표(외부 자료 붙이기), 동 사이 출근 이동 시간(2023.4) | 4장 |
| `02_서울전체/` | `f2_운행정정.py` 정류장–행정동 운행 횟수 정리 → `f1_두잣대.py` 기준 A·B, 버스 부족 동 63곳, 28가지 다시 계산 | 5~10장 |
| `03_강동/` | `f3_이동OD.py` 강동 관련 동 사이 이동, `f4_개선안근거.py` 강동 동별 지표, `노선수_비교.py` 노선 수 0.42배 | 12~17장 |
| `04_개선안1_강동안/` | 이동 종류, 거리별 버스 연결, 경로 후보, 운행 계획, 지도, 경제성 | 19~22장 |
| `04_개선안2_시간대/` | 동×시간 패널, 시간 불일치, 동네 유형, 주말, 노선별 출근 운행비 | 24~28장 |
| `04_개선안3_송파/` | 생활이동 요약, 동 사이 이동 vs 버스 연결, 우회율, 노선 초안·배차 | 30~34장 |
| `out/` | 단계별 결과 CSV | |
| `verify.py` | 발표 숫자 대조 | |

## 주의

- 동 사이 이동은 구할 수 있는 가장 가까운 시점인 2023년 4월 자료라, 선정에는 쓰지 않고 강동 이동과 개선안 운행에만 썼습니다.
- 개선안의 차 1대당 승객은 '동 사이 이동의 18%가 버스를 탄다'는 가정 값입니다. 버스 증가율(+27%)은 실측 기준입니다.
- 주민등록 '세대'는 실제 가구와 다릅니다.
